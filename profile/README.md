# Asociación de Cooperativas Argentinas (ACA)

Ésta organización contiene los repositorios que alojan el código fuente de los distintos proyectos, servicios y aplicaciones de ACACOOP.

Se integran tanto proyectos de desarrollo interno como proyectos de desarrolladores externos.

El fin de esta organización es centralizar los contenidos de los proyectos llevados a cabo en ACACOOP, tanto su código fuente como su documentación, implementación y despliegue automatizado.
